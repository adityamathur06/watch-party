# Watch Party

Watch Party is a real-time web application that allows friends to watch videos together in sync and communicate in shared rooms.

> ⚠️ This project is currently under active development.

---

## 🚀 Tech Stack

- HTML, CSS, JavaScript
- Firebase Authentication
- Firebase Firestore

---

## ✅ Current Features

- User authentication (sign up, login, logout)
- Persistent user sessions
- Protected app routes
- Clean UI with modal-based flows
- Create Room / Join Room UI (logic in progress)

---

## 🛠 Planned Features

- Real room creation and joining
- Real-time chat
- Video playback synchronization
- Voice chat support
- Improved room management

---

## 📌 Status

This project is being actively developed.  
Core room logic and real-time features are currently in progress.
